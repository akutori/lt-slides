# Filamentとは

<!-- さて、まずはフィラメントが何なのか、公式の説明を読みながら確認します。 -->

---

<!-- header: Filamentとは -->
<!-- footer: https://filamentphp.com/docs/5.x/introduction/overview<br>https://filamentphp.com/docs/5.x/introduction/installation<br>https://filamentphp.com/docs/5.x/introduction/version-support-policy<br>https://livewire.laravel.com/docs/4.x/quickstart<br>https://packagist.org/packages/filament/filament -->

- Laravel向けのServer-Driven UI(SDUI)フレームワーク
- UIをテンプレートではなく、PHPの設定オブジェクトで定義する
- 土台はLivewire(PHPだけで動的な画面を作れる仕組み)、Alpine.js、Tailwind CSS
- 管理パネルのほか、ダッシュボードやフォーム中心のアプリにも使える
- ライセンスはMIT
- 現行は5系(2026年10月時点の最新は v5.10.1)
- 5系の要件: PHP 8.2以上、Laravel 11.28以上、Tailwind CSS 4.1以上

<!-- ここからは、モデルから管理画面ができるまでを、順に見ていきます。 -->

- 前提: Laravelのプロジェクトがすでにある
- 公式ドキュメントのコマンド(2026年10月時点)

```bash
composer require filament/filament:"^5.0"    # 本体を入れる
php artisan filament:install --panels        # AdminPanelProvider.php を作る
php artisan make:filament-user               # ログイン用のユーザーを作る
```

- /admin を開き、作ったユーザーでサインインする
- Windows PowerShell では ^ が無視されるため、~5.0 と書く(公式の注記)

- Customer モデルのリソースを作る(公式ドキュメントの例)

```bash
php artisan make:filament-resource Customer --generate
```

```text
app/Filament/Resources/Customers/
+-- CustomerResource.php
+-- Pages/    CreateCustomer.php  EditCustomer.php  ListCustomers.php
+-- Schemas/  CustomerForm.php
+-- Tables/   CustomersTable.php
```

- --generate は、モデルのDBカラムをもとにフォームと表を生成する
- 他のオプション: --simple(モーダルで完結)、--view(閲覧ページを追加)
- メニューに出ないときは、モデルポリシーの viewAny() が true か確認する

- フォームは Schemas、表は Tables のクラスで定義(公式ドキュメントから抜粋)

```php

    TextInput::make('name')->required(),
```

```php

    TextColumn::make('name'),
    TextColumn::make('email'),
])
```

# 向き不向きと注意

<!-- ここからは、使うときの注意点と、向かない場合を順に見ていきます。 -->

---

<!-- header: 向き不向きと注意 -->
<!-- footer: https://filamentphp.com/docs/4.x/upgrade-guide<br>https://filamentphp.com/docs/5.x/upgrade-guide<br>https://filamentphp.com/docs/5.x/introduction/version-support-policy<br>https://filamentphp.com/docs/5.x/navigation/custom-pages<br>https://filamentphp.com/docs/5.x/introduction/overview -->

- 版の違い: 4系でディレクトリ構成が変更、5系はLivewire 4が必要
- バグ修正の期限(2026年10月時点): 3系は2026年8月1日、4系は2027年1月15日
- 独自の画面は make:filament-page で作成、実体はLivewireのコンポーネント
- Livewireを避けたい場合、公式はLaravel Novaを代替に挙げている
- 公式以外のプラグインは、品質や互換性が保証されない
- 【差し込み: Filamentを使って困った点、または検討中の理由】

# まとめ

- FilamentはLaravel向けのSDUIフレームワークで、UIをPHPの設定オブジェクトで定義する
- 管理パネルは composer require と filament:install --panels で用意できる
- make:filament-resource で、一覧・作成・編集のページとフォーム・表のクラスが生成される
- 版ごとに要件と標準の構成が異なるため、使う版の公式ドキュメントで確認する
- 独自の画面はLivewireで作るため、Livewireを避けたい場合は公式が挙げる代替も比較する
