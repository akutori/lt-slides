# memo

## 元ネタ

ユーザー提供の個人的な振り返りメモ、2026-09-01作成を元にLT化したもの。
情報源はユーザー提供の資料のみで、新規のWeb調査は行っていない。

## 匿名化の方針

会社名・人物名・GCPプロジェクト名・内部チケット番号は、構成案の時点でスライドから除外・一般化した。
「客先」「チームメンバー」等の一般名詞に置き換えている。

## 元ネタとの対応

- 導入の数字(75日・52日・498コミット)、fix:feat比率、実機発覚率(概算) → 元メモ「結論」節
- 全体像のMermaid図 → 元メモの図(A→B、C→D→E、B→F、D→F、E→F の5エッジ)を再構成したもの。
  元図は「エスカレーションが省かれる」ノードを「レイヤーを絞らなかった→認知負荷超過」の下流に置き、そこから結論ノードへつなぐ1本のチェーンだった。
  スライド版はこれをあえて「失敗1・2・3」の3スライド構成に合わせ、3つを並列の原因として結論ノードへ直接つなぐ形に描き直している。因果関係を単純化した意図的な再構成であり、元図の描き漏れの修正ではない。
- 失敗1(環境) → 元メモ 部門3(環境戦略) 3-1
- 失敗2(レイヤー) → 元メモ 部門1(スコープ・タスク管理) 1-1、コミットバーストの評価は1-1本文の7月306コミット(全体54%)の記述に基づく
- 失敗3(エスカレーション) → 元メモ 部門4(意思決定・エスカレーション) 4-1
- それでも機能した仕組み → 元メモ「良かった点」節
- 次にやること → 元メモ「確認してほしいこと(次案件の着手前に決めること)」節。元メモの表現に合わせ、タイミングは「最初のスプリント」ではなく「着手前」としている
