# 「書いたつもり」を疑う技法

<!-- さて、ここからは、悲観的開発手法に取り入れられそうな技法を紹介します。 -->

---

<!-- header: 「書いたつもり」を疑う技法 -->
<!-- footer: https://library.libecity.com/articles/01KXB75HC6S3NSE7MM7SSGJ2J0<br>https://press.uchicago.edu/ucp/books/book/chicago/T/bo6035368.html -->

- 暗黙知: 言葉にしきれない知識(Polanyi)
- 記事での意味: 頭にあるが、指示書に書いていない前提

|  | 賢いモデル | 小型モデル(Haiku) |
| :-- | :-- | :-- |
| 曖昧な指示 | 文脈から補う | 補えない |
| 書き手から見ると | 書いたつもりになる | 推測として表に出る |

記事の主張: リベシティ ノウハウ図書館(2026/07/13)
